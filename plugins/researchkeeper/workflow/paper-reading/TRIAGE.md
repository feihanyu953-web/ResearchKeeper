# Triage 快速筛选协议

本文件承载批量入库前的论文优先级筛选规则。触发场景：`rsk diff` 列出未入库论文后、批量精读入库前（见 `workflow/knowledge/INGEST.md` 批量入库 N≥5 前置）；或用户给出一批候选论文要求"先筛一遍"。

## 目的

仅用 title + abstract 完成优先级评级，避免"逢文必读"的全文精读成本：

- **高**：进入全文精读 + 完整入库（`workflow/knowledge/INGEST.md` 入库流程）
- **中**：仅入 literature 索引（精读状态 = 待深读），暂不花全文精读成本
- **低**：跳过，标记原因

## 输入

- `rsk import --from-zotero` 导出的 `outputs/zotero_export.json`（含 title + abstract）
- 或 `rsk diff` 输出的未入库列表
- 或用户直接提供的论文清单（标题 + 摘要）

## 研究画像（价值对齐基准）

评级时将"一句话贡献"与以下画像交叉比对：

- 研究子领域：按工作区实际研究方向声明（如电催化（实验）/ C-N 偶联 / 电氧化 / 界面水微环境 / DFT / MLFF+MD）。
- 用户当前课题重点：以会话上下文为准。
- 可迁移性：方法学论文（新泛函 / 新 MLFF 架构 / 新原位技术 / 新描述符）即使体系不对口，至少评"中"。

## 执行方法论（对每篇论文）

1. **数据提取**：读取 title + abstract。字段缺失标"N/A"。
2. **IMRaD 五段解构**（仅用摘要文本，禁止引入外部知识）：
   - 背景（Context）：领域动机
   - 缺口（Gap）：具体局限或未解决问题
   - 方法（Method）：体系 / 框架 / 实验或计算设计
   - 发现（Findings）：定量结果或核心观察
   - 结论（Conclusion）：意义或未来工作
   - 摘要未包含的部分标"**摘要未详述**"。
3. **一句话贡献**：创新点压缩为一句高密度表述。
4. **价值评级**：
   - **高 / 中 / 低** + 两条基于证据的理由（如"界面水 SEIRAS + AIMD 双证据链，直接对应当前课题"或"有机合成体系，方法不可迁移"）。

## 输出格式

```text
### [序号] 论文标题
- 一句话贡献：……
- IMRaD：背景 … / 缺口 … / 方法 … / 发现 … / 结论 …（缺项标"摘要未详述"）
- 评级：高 / 中 / 低
- 理由：1) … 2) …
```

末尾输出汇总表：

| 评级 | 篇数 | 论文序号 |
|---|---|---|
| 高 | n | … |
| 中 | n | … |
| 低 | n | … |

## 批量执行

- 每批 10-20 篇；N 较大时按 `agent_count = ceil(N / 10)` 分片子 agent 并行（遵循
  `workflow/knowledge/INGEST.md` 的单轮 ≤8 agent 并发硬上限），主 AI 汇总评级表。
- 子 agent 只做评级，不读全文、不入库、不写任何 kb/wiki 文件。

## 评级后的动作

| 评级 | 动作 |
|---|---|
| 高 | 走 `workflow/knowledge/INGEST.md` 入库流程（全文精读 + 活动模块 coverage + 评价类记录 + 文献信息记录） |
| 中 | 仅写 literature 索引记录（metric=精读状态，value=待深读）+ 跑 INGEST Step 3 的 bibliography 书目流水线生成文献信息记录（题目/作者/DOI 天然可用，成本低）；用户点名时再升级全文精读 |
| 低 | 不入库；在 triage 输出中标注原因，备查 |

## 硬规则

- 仅使用 title + abstract，禁止引入外部知识或凭期刊名/作者名气评级。
- 摘要模糊则如实反映模糊性，不编造细节。
- 评级理由必须锚定摘要中的具体内容（体系 / 方法 / 数据），禁止空泛表述（"很有价值"）。
- triage 是筛选不是精读：不输出 10 板块内容，不做机理分析。
